# Capstone Web Application

This is the repository for the capstone web application for the internship track.

## Description
This project is a React frontend application built using Vite, TypeScript, and CSS. It showcases modern frontend development practices.

## How to run
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start dev server:
   ```bash
   npm run dev
   ```
